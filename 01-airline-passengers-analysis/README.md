# ✈️ Анализ поведения и сегментация авиапассажиров

## 📋 Описание проекта
В данном проекте проводится статистический анализ данных пассажиров авиакомпании с целью выявить ключевые факторы, влияющие на частоту перелетов, изучить предпочтения клиентов в зависимости от пола и целей поездки, а также построить регрессионную модель прогнозирования.

## 🎯 Задачи исследования
1. Проверить статистические гипотезы о различиях в частоте полетов между мужчинами и женщинами ($t$-тест).
2. Исследовать связь между целью поездки (бизнес / личные цели) и поведением пассажиров.
3. Оценить взаимосвязь между важнейшими характеристиками полета (комфорт, точность, частота рейсов) и демографическими признаками ($\chi^2$-тест).
4. Построить модель парной линейной регрессии для оценки влияния годового дохода на количество перелетов за год.

## 🛠 Инструменты и библиотеки
* **Язык:** Python
* **Библиотеки:** Pandas, NumPy, SciPy, Statsmodels, Matplotlib, Seaborn
* **Интерпретация:** Статистическое тестирование, интервальное оценивание, регрессионный анализ

## 📊 Ключевые выводы и результаты
* **Частота полётов:** Мужчины в выборке совершают в среднем больше полётов за год, чем женщины ($3.45$ против $2.76$), разница статистически значима ($p < 0.05$).
* **Предпочтения:** Выявлена сильная связь между полом пассажира и приоритетами в полете (женщины чаще выбирают комфорт, мужчины — точность и частоту рейсов).
* **Влияние дохода:** Построена модель линейной регрессии, которая показала высокую связь между годовым доходом и числом полетов ($R^2 \approx 0.698$). Около 70% вариации частоты перелетов объясняется уровнем доходов пассажира.
